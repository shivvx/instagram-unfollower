## ✨ Features

- 🔍 **Accurate Non-Follower Audit:** Rapidly identifies accounts you follow that do not follow you back.
- ⭐ **Whitelist Shield:** 1-click star tagging to protect close friends, family, and creators from accidental unfollow actions.
- 💾 **Automatic Data Persistence:** Whitelists are preserved in browser `localStorage` and can be exported or imported as JSON backups.
- 🛡️ **Anti-Detection Rate Shield:** Configurable delay intervals, batch cooldowns, and randomized human jitter to protect your account from Instagram action blocks.
- 🎯 **Smart Filter Chips:** Filter in seconds by **Verified** badges, **Private** profiles, or accounts with **No Profile Picture** (bot cleaner).
- 📊 **Spreadsheet & JSON Export:** Download audit results directly as formatted `.csv` files (for Microsoft Excel and Google Sheets) or structured `.json`.
- 🎨 **State-of-the-Art Dark UI:** Frosted glassmorphism, responsive dock layout, and micro-animations.
- 🔒 **100% Private & Safe:** Operates strictly within your active Instagram session—your credentials and data never leave your browser.

## 🖥️ How To Use (Desktop)

### 1. Get the Code Snippet
Choose either option to copy the script:
* **Option A (Web Portal):** Open the [GhostGram Web Portal](https://shivvx.github.io/instagram-unfollower/) and click **Copy Code Snippet**.
* **Option B (Direct Raw File):** Open **[ghostgram.min.js](https://raw.githubusercontent.com/shivvx/instagram-unfollower/main/ghostgram.min.js)**, select all (`Cmd + A` / `Ctrl + A`), and copy.

### 2. Run It on Instagram
1. Open [instagram.com](https://www.instagram.com) in your browser and make sure you are logged in.
2. Open your browser developer console:
   - **Windows / Linux:** `Ctrl + Shift + J` or `F12`
   - **macOS:** `Cmd + Option + I`
   *(If your browser displays a paste warning, type `allow pasting` and press Enter).*
3. Paste the code into the Console prompt and press **`Enter`**.
4. The **GhostGram** dashboard will instantly mount on your screen!
5. Click **Start Account Scan** to begin detecting accounts that don't follow you back.
